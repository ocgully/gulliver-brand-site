Nobis Command Center

Order processing and fulfillment application which allowed for 1 tap order fulfillment for existing customers. Issuing a bill of materials, and printing out all necessary postage, to be handed off to shipping department to fulfill orders. Integrated into OsCommerce for realtime notifications of purchasing.

CompanyNobis Technologies
Years2004–2009
PlatformsDesktop
TypeGraveyard

What was built

Designed and implemented an end-to-end order management system that streamlined business operations. Features: Order Fulfilment; Order Refunding; Postage Printing and Payment; Inventory Management; Purchase Notification. Built with: Visual Basic, MySQL, OsCommerce.

Why it ended

We shut down Nobis Technologies in 2009, no longer needed.
