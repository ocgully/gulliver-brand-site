OsCommerce Verisign Plugin

The plugin utilized Verisign (now owned by PayPal)'s payflow link system. A system that required the user to leave a customers website to go to one owned by Verisign and fill out their credit card information. A process that was less than optimal, and would on frequent occasion result in orders not being completed, as it was unclear to the user how to finalize the transaction. Using the plug-in I developed, it emulated the process of Verisign's more expensive premium service named Payflow Pro to the customer.

CompanyNobis Technologies
Years2004–2009
PlatformsWeb
TypeGraveyard

What was built

Integrated the equivelence of the premium Verisign Payflow service, using the free Payflow Link API. This resulted in a much better customer experience for free, and increased conversion rates.

Why it ended

Eventually the need was replaced byPayPal, and better online Credit Card Processing services like Stripe.
