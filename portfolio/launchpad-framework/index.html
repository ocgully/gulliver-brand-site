LaunchPad Framework

A game development framework that allowed for rapid prototyping and development of mobile games. The framework was used to create several successful Disney mobile games.

CompanyDisney Interactive
Years2013–2015
PlatformsiOSAndroidWeb
TypeShipped

What was built

Architected and led development of a cross-platform game development framework that accelerated Disney's mobile game production pipeline. Features: Cross-platform compatibility (iOS, Android, Web); Modular architecture for rapid prototyping; Integrated analytics and A/B testing; Automated build and deployment pipeline; Comprehensive asset management system; Configurable UI framework; Integrated IAP and monetization tools. Built with: Objective-C, Java, C#, Unity3d.
