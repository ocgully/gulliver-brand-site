Colophon

This site is a receipt.

Every page here was generated by Axon, a programming language the operator wrote. Not a framework on top of a language, and not a theme: the compiler, the widget renderer, the markdown parser and the JSON parser are all Axon source, and the generator that assembles this site is one more Axon program. It reads a directory of data files and writes a directory of HTML.

The pipeline is short on purpose. A directory of JSON files holds the content. A validation gate parses each one exactly once and refuses the build by file name and field name if a record is missing something or is the wrong shape. Only then does a page module per section turn records into a widget tree, a document shell writes the head, the landmarks and the footer around that tree, and one stylesheet is generated from a table of design tokens. The whole run writes the site to disk in well under a second.

Nothing in the run reads a clock and nothing reaches the network, so two builds of the same source produce byte-identical output. That is not a speed claim. It is what makes the site testable: an acceptance harness can assert against the artifact instead of against a screenshot of it.

What this site does not do

  • No JavaScript. The output carries no script tag and no inline handler, on any page, and an assertion over the built tree proves it on every build.

  • No cookies. Nothing here sets one, because nothing here runs.

  • No analytics, no tracking pixels, no session identifiers.

  • No third-party requests of any kind. No web fonts, no CDN, no embeds. Every byte the browser fetches for this site comes from this origin.

  • No network access at build time either. Axon has no network capability at all, which is a real limitation and also a real guarantee.

Provenance

The six Axon batteries this site compiles against are vendored into the repository from git objects at one pinned commit, with a SHA-256 digest recorded per file. The digests, not the commit id, are the integrity gate: the pin is local-only today, so a commit id nobody else can fetch would be provenance theatre.

Zero commits to the language repository were needed to ship this site. Everything Axon could not yet do was handled by a wrapper in this repository and written down in the log below.

That rule is why the log is worth reading. A gap that can be quietly patched upstream never gets counted, and a language that is only ever used by the person improving it never has to admit what it costs.

The gap log

Every gap this build ran into, with the workaround that shipped instead. Some are ordinary young-language holes. Some are funnier than that: writing a file cannot create the directory it goes in, and Axon has no way to make a directory, so producing one costs the generator a blanket process-execution grant. The table is also an entry about itself. The markdown renderer that draws it emits a heading, an anchor and a table that this site's own gates refuse, so three string rewrites sit between the source file and this page.

The list below is rendered from GAPLOG.md in this repository. The build copies that file into the generator's read root first, because the generator cannot see above its own directory.

Axon Gap Log

This site is generated entirely by Axon (repo currently private), the language this project's operator wrote. Building a real site on a young language surfaces real gaps. This file is where they go.

The standing rule: every Axon gap encountered while building this site gets

  1. a project-local wrapper or idiom — the workaround lives here, in this repo, and
  2. an entry in this log, naming the gap plainly.

Zero commits to ~/git/ailang are required or permitted by this milestone. The language repo is read-only to this project: batteries are vendored from git objects at a pinned SHA (see vendor/axon/VERSIONS.md), and nothing here patches upstream. If a gap turns out to be genuinely unwrappable, it becomes a surfaced blocker — not a quiet fork of ailang.

Nothing gets silently absorbed. Every shell line in the build harness exists because of a gap named below, and this log is the source material for the site's Colophon page.

How to add an entry

When a new gap bites, append a row with the next G-NN id: state the gap in terms of what Axon cannot do (not what your code failed at), name the wrapper or idiom that works around it — or write None and say why, as in G-08 — tie it to the requirement it affects, and date it. If the workaround is code, land the wrapper in the same commit as the log entry.
